# Orbit · présentation BTL

Présentation d'Orbit, l'outil de pilotage des campagnes de BEYOND THE LINE Africa : intérêt, coût, valeur ajoutée et retour sur investissement.

En ligne : https://eldoradodesign1.github.io/orbit-presentation/

Commandes : flèches ou glisser pour naviguer, **N** notes de l'orateur (avec durées, environ 55 min), **O** sommaire, **F** plein écran. Le calculateur de la slide « Testons vos hypothèses » se règle en direct.

Conçu par Eldorado_design pour BEYOND THE LINE Africa. By Eldo.
